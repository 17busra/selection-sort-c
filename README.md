# selection-sort-c
C dili ile yazılmış temel Selection Sort (Seçmeli Sıralama) algoritması.

Bu proje, C programlama dili kullanılarak yazılmış temel bir **Selection Sort** algoritması örneğini içerir. Verilen bir tam sayı dizisindeki en küçük elemanı bularak sırasıyla başa alır ve diziyi küçükten büyüğe doğru sıralar.

**Kullanılan Dil:**
* C

**Örnek Dizi Girişi:**
`29, 5, 8, 11, 2, 24`

**Çıktı:**
`2, 5, 8, 11, 24, 29`
